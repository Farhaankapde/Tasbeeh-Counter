1. DHIKRS SCREEN
========================================

Simplify the Dhikrs page.

The Dhikr creation/edit form should contain ONLY:

- Dhikr name (required)
- Target

Remove these fields completely:
- Arabic text
- Translation / meaning

Do not keep them as optional fields. Remove them from the UI and from the creation/edit experience.

TARGET OPTIONS:

The target selection should ONLY have:

- None
- Custom

Remove the preset target buttons:
- 33
- 99
- 100

The user can therefore either:
- choose None
- choose Custom and enter any target number

Do not force a target.

Examples:

Subhanallah → None
Bismillah → None
Alhamdulillah → Custom: 100
Astaghfirullah → Custom: 1000

The target remains optional.

========================================
2. HISTORY SCREEN
========================================

Keep History.

History represents:
"Past counting sessions"

It is NOT the current Dhikr library.

Keep a clear title:

History

Subtitle:

Your recent remembrance sessions

Each history item should clearly display:

- Dhikr name
- Date
- Time
- Number of repetitions in that session

Use a clean presentation such as:

Subhanallah
18 Sep 2026 • 7:43 PM
33 repetitions

Bismillah
18 Sep 2026 • 7:25 PM
11 repetitions

Avoid the current "+33" style if possible.
Use "33 repetitions" or an equally clear presentation.

Do not combine separate sessions into one History item if they were separate saved sessions.

----------------------------------------
DELETED DHIKRS
----------------------------------------

Deleting a Dhikr from the Dhikr library must NOT delete its historical sessions.

Example:

User has:
Subhanallah → 33 repetitions

User later deletes Subhanallah.

The old session should still appear in History.

History represents what the user practiced in the past.

Dhikrs represents what the user currently has in their library.

If useful, a deleted Dhikr may have a subtle "Deleted Dhikr" indication, but this is optional and should not dominate the UI.

----------------------------------------
HISTORY EMPTY STATE
----------------------------------------

If there are no sessions:

"No practice history yet"

"Your counting sessions will appear here."

Keep the empty state clean.

History remains completely local/offline.

========================================
3. STATS SCREEN
========================================

Simplify the Stats page significantly.

Stats should answer:

"How much have I practiced?"

It should NOT display individual Dhikr targets.

----------------------------------------
PRIMARY STATISTICS
----------------------------------------

Show exactly these three:

TODAY

Total repetitions counted today across ALL Dhikrs.

THIS WEEK

Total repetitions counted from the beginning of the current week through today, across ALL Dhikrs.

ALL TIME

Total repetitions recorded across ALL Dhikrs.

Example:

TODAY
329

THIS WEEK
329

ALL TIME
2,644

It is valid for Today and This Week to have the same number if the user has only practiced today during the current week.

----------------------------------------
REMOVE THESE SECTIONS
----------------------------------------

Remove the entire:

"Dhikr Target"

section.

Do NOT show:
- current Dhikr target
- target progress
- target percentage
- 33 / 33
- 100 / 100

Targets belong to individual Dhikrs and the Counter screen.

Also remove:

"All-Time Practice"

because it duplicates the All Time statistic.

Do not show duplicate statistics.

----------------------------------------
BY DHIKR
----------------------------------------

Below the three primary statistics, add:

By Dhikr

Show lifetime repetition totals for Dhikrs currently in the user's library.

Example:

By Dhikr

Subhanallah              1,240
Alhamdulillah              980
Bismillah                  621

Only show repetition totals.

Do NOT show targets here.

If there are no Dhikrs, show a clean empty state.

----------------------------------------
DELETED DHIKRS AND STATS
----------------------------------------

Deleting a Dhikr must not incorrectly erase its historical contribution from global All Time statistics.

However, "By Dhikr" should represent the CURRENT Dhikr library.

Therefore:

- Current Dhikr → appears in By Dhikr
- Deleted Dhikr → no longer needs to appear in By Dhikr
- Historical activity from deleted Dhikr → remains included in All Time

Do not double-count any migrated or legacy data.

5. TARGET COMPLETION
==================================================

If the user has set a target and reaches that exact target:

- Play a noticeable, satisfying completion sound.
- Provide haptic feedback if vibration is enabled.
- Show a subtle visual completion indication.
- Do NOT show a large intrusive popup.
- The completion sound must be clearly noticeable and different from the normal tap sound.
- The sound should be pleasant, warm, satisfying, and appropriate for a Tasbeeh app.
- It should be approximately 1–2 seconds.
- It can contain multiple tones/chime layers rather than a tiny single beep/ting.
- It should take the user's attention without being harsh, alarming, or excessively loud.
- Respect the existing Sound ON/OFF setting.
- Keep the normal counter tap sound unchanged.

The completion effect must trigger only once when the target is reached.

Example:
Target = 100

99 → normal counting
100 → completion sound + haptic + visual feedback
101 → no second completion sound

If the user resets the counter and reaches the target again, the completion effect should be available again.

If there is NO target, there should be NO target-completion effect.

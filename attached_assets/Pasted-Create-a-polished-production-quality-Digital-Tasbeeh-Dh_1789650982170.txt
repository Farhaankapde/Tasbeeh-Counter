Create a polished, production-quality **Digital Tasbeeh / Dhikr Counter mobile app** called **Tasbeeh Counter**.

Use the attached reference image as the **primary visual reference** for the home screen. Recreate the overall visual style, hierarchy, proportions, colors, spacing, shadows, depth, and premium feel using actual interactive UI elements.

Do not use the reference image as a static background or screenshot. Recreate the interface as a fully functional application.

The app should initially be focused on Android, but structure it so it can be extended to other platforms later.

---

# CORE CONCEPT

This is a simple, elegant digital Tasbeeh counter.

The main user flow should be:

**Open app → Select Dhikr → Press the large Tasbeeh button → Counter increases → Optional vibration/sound → Count automatically saved.**

The experience should feel:

* Premium
* Calm
* Elegant
* Spiritual
* Tactile
* Modern
* Minimal
* Islamic

The counter should be the clear primary focus of the application.

---

# DHIKR SELECTOR

Below the greeting, create a large rounded selector.

Default selection:

**SubhanAllah**

The selector should contain:

* Circular dark-green icon
* Arabic calligraphy where appropriate
* Dhikr name
* Down arrow

Tapping it should open a polished selection interface.

Include these default Dhikr:

1. SubhanAllah
2. Alhamdulillah
3. Allahu Akbar
4. La ilaha illallah
5. Astaghfirullah
6. SubhanAllahi wa bihamdihi

Alhamdulillah → 120

Astaghfirullah → 56

# COUNTER BEHAVIOR

Every tap must:

1. Increase the counter by exactly 1.
2. Immediately update the display.
3. Save the new count.
4. Trigger vibration if enabled.
5. Play sound if enabled.
6. Animate the button press.
7. Optionally animate the changing digits.

The counter must remain saved when:

* The app is closed.
* The app is reopened.
* The phone is restarted.

The user must never unexpectedly lose their count.
